- TDD evidence, two new `/decide` rules (`/decide` 1.4.0, operator 1.5.0, peer 1.1.0, rules 1.7.0). DEC-21 `script`: the coder's report shows each proof test and each fix-round test red, then green, as labelled lines (`RED <test> -- ` failing without the change, `GREEN <test> -- ` passing with it, run with the profile's targeted-test command), or `CANNOT FAIL FIRST <test> -- <reason>` (docs only, a pure refactor, no targeted-test command in the profile). DEC-22 `script`: the `reviewer` and `re-reviewer` revert only the production part of the diff (three-dot, from the merge-base) in a scratch worktree made with `git worktree add --detach` under `mktemp -d`, never the coder's worktree or branch, run each proved test alone with the targeted-test command (their one exception to read-only), and write `PROOF CHECK <test> -- fails|passes|not checked: <reason>|exempt`. `fails` means the test built, ran and failed; a build failure or anything that kept it from running is `not checked: <reason>`. A `CANNOT FAIL FIRST` test is exempt from the revert check; the reviewer writes `exempt` and judges the reason. A pass is a CONFIRMED finding, "proof does not prove", and blocks the merge until a later `fails` of that test (`not checked` and `exempt` never clear it). Cleanup undoes the revert and runs a plain `git worktree remove` (never `--force`; a refusal leaves the worktree and reports its path).

Names are exact and end at the first ` -- `, so pytest ids, Go subtests and jest names with colons work; `--test` repeats; `--coder --json` prints the proved and exempt tests for the ledger; `--reviewer` takes the required tests from `--coder-report` (or `--test`) and needs no line for an exempt test; the CONFIRMED finding is matched in any case and names the test exactly. `scripts/proof-revert.mjs` (read-only) prints the revert commands from `git diff --name-status -M <merge-base> <head>`: modified and deleted files restored with `git checkout <merge-base> -- <file>`, added files removed, renames handled; tested on a throwaway repo.
